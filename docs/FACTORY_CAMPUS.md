# 가상 해안 제철소

주문과 소재 ID를 유지한 채 원료 반입, 제선·제강·연주, 압연·표면처리, 검사·포장, 창고·항만·배송을 따라가는 합성 운영 모델이다. 실제 제철소의 측량도나 물리 시뮬레이터는 아니다.

## 배치와 이동

- 원료장과 제선·제강은 서쪽, 탄소강 압연은 중앙, 도금·전기강판은 동쪽, 스테인리스·티타늄 라인은 남쪽에 배치했다. 동쪽 창고와 해안 부두로 출하한다.
- 158개 설비와 31개 시설을 공정 방향에 맞춰 배치했다. 화면 장식용 격자 대신 서버와 화면이 공유하는 경로 위에 도로·철도·롤러를 그린다.
- 트럭은 건물 사이 도로를, 용선차·용강차는 철도를, 공정 사이 소재는 롤러를 따라 이동한다. 다른 설비와 건물의 평면 영역을 피하고 각 설비의 인수·인계 지점에 접근한다.
- 포장 완료품은 트럭으로 창고에 운반한다. 하역 크레인이 내려놓는 위치와 창고 재고 위치가 이어진다. 차량 앞부분도 이동 방향과 일치시켰다.
- 124개 일반 롤러 경로에도 서버가 관리하는 이송 시간과 소재 점유 위치를 부여했다. 출발·이동·도착 상태를 기록하며 화면은 이 상태를 보간한다.

거리와 속도는 축약한 장면 단위다. 평면 경로 검사는 설비·건물 영역을 대상으로 하며, 모든 장식물의 체적 충돌이나 차량 교통 신호·회차·빈 차 복귀까지 재현하지는 않는다. 생산 순서와 자원 점유는 서버가 결정한다.

## 화면 조작

설비 이름의 불투명한 배경을 없애고, 전경에는 구역 이름만 표시한다. 공정 안에서는 선택하거나 가리킨 설비의 이름을 표시한다. 선택한 건물은 벽을 낮춰 내부 공정을 볼 수 있다.

3D 화면 아래의 화살표 네 개로 시점을 이동하고, 확대·축소·범위 맞춤을 사용한다. 화살표 키, `+`·`-`, `Home`도 지원한다. 직접 이동하거나 회전하면 소재 따라가기를 해제해 카메라가 되돌아오지 않게 한다. 카메라 조작은 생산 상태를 변경하지 않는다.
