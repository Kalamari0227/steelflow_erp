# 2026-10-30 SteelFlow demo

## 준비

README의 두 서버를 실행한 뒤 `http://127.0.0.1:5173`을 엽니다. Chrome 또는 Safari의 WebGL 지원 환경을 권장하며, 데모 리허설은 실제 Chrome에서 확인합니다. 1440×1000 이상 창에서 사이트와 상세 패널을 함께 볼 수 있습니다. 화면의 Synthetic environment 표시를 유지합니다.

시작 전 NORMAL을 선택하고 Reset을 누릅니다. 시각 08:00 UTC, Step 0/24, 총 24개 코일, 총 질량 318t가 기준입니다. 1×를 선택하면 정지 상태가 유지됩니다.

## 3분 시연 순서

1. **전체 흐름 (30초)** — 주문·생산·출하 KPI를 소개하고 공장, 코일 야드, 트럭 출하, 항만을 가리킵니다. 드래그로 회전하고 스크롤로 확대합니다. Reset camera로 초기 시점을 복원합니다.
2. **추적성 (30초)** — 야드의 코일을 선택합니다. 오른쪽에서 coil→lot→order→customer→location→shipment를 설명합니다. 2D inventory에서도 동일 정보를 선택할 수 있음을 보여줍니다. 주문 검색에서 `Northstar`를 입력했다가 지웁니다.
3. **정상 기준 (30초)** — NORMAL에서 Step을 8회 눌러 12:00 UTC로 이동합니다. O-1001은 해상 운송 단계입니다. 같은 tick 비교를 위해 자동 재생보다 Step을 사용합니다.
4. **지연 (30초)** — DELAY를 선택하면 새 실행의 baseline으로 돌아갑니다. Step 8로 이동합니다. O-1001은 야드에 있고 위험 주문 2개, 납기 대비 2h 지연을 확인합니다. 위험 설명은 ETA와 due_at을 비교한 로컬 규칙입니다.
5. **복구 (30초)** — RECOVERY에서 Step 8로 이동합니다. O-1001은 항만 단계이며 2h를 회복해 납기를 맞춥니다. 대체 라인 배정과 위험 설명을 확인합니다.
6. **재현·감사 기록 (30초)** — 4×로 Play해 배송 완료까지 확인합니다. Pause와 Reset을 시연합니다. Event history는 현재 실행을 표시하고, 백엔드는 이전 실행도 보존한다고 설명합니다. NORMAL/Reset/1× 상태로 종료합니다.

## 생산 공정 시연 — 약 3분

1. [생산 오버뷰](http://127.0.0.1:4173/?workspace=production)를 엽니다. 정상 생산을 선택하고 Reset합니다. 생산 배치 9개, 총 198t는 물류 데이터와 별도로 만든 합성 예제임을 설명합니다.
2. 공장을 클릭하거나 하단 공정 목록에서 **제선 → 제강 → 연주**를 차례로 엽니다. 내부 작업에서 원료 장입, 출선, 출강·정련, 연속주조·절단을 선택합니다. 전체 공정 버튼으로 돌아갑니다.
3. 제품 경로를 **BLOOM**, **BILLET**으로 바꿉니다. 연주 이후 정정·검사와 제품 입고로 이어지고 열연·냉연을 거치지 않는 반제품 판매 예제를 보여줍니다.
4. 정상 상태에서 Step을 8회 누릅니다. **HR** 배치는 열연 판매 제품, **CR** 배치의 현재 HR은 후공정 소재임을 비교합니다. Step 10에서는 CR 경로의 냉연은 판매 제품, GI 경로의 냉연은 도금 소재입니다. 오른쪽 소재 변환 이력과 현재 공정 버튼을 확인합니다.
5. 도금 공정을 열고 **GI / GA / EG / HGI**를 선택합니다. GA의 합금화, EG의 전해도금, HGI 경로의 냉간압연 생략과 산세·표면준비를 보여줍니다. 정정·검사와 제품 재고도 선택합니다.
6. GI 배치로 정상·지연·회복을 같은 Step 11에서 비교합니다. 정상은 도금 작업, 지연은 냉연 작업, 회복은 냉연에서 도금으로 운송 중입니다. 회복의 HSM-B 배정은 열연 내부 작업 목록에서 확인합니다. 소재 계보는 현재까지 완료된 변환만 표시합니다.
7. **2D 공정**으로 전환해 같은 배치와 공정을 선택합니다. 정상 생산, Reset, 1×로 종료합니다. 생산 상세 데이터가 물류 주문·코일로 자동 이관되는 단계는 아직 포함하지 않는다고 설명합니다.

생산 시연 화면: [3D 개요](evidence/production-3d-overview.png), [공정 상세](evidence/production-3d-detail.png), [HGI 경로](evidence/production-route-hgi.png), [모바일](evidence/production-mobile-390.png), [WebGL 중단 대체 화면](evidence/production-webgl-fallback.png). 아래 기존 영상은 물류 흐름을 녹화한 자료이며 생산 상세 화면은 포함하지 않습니다.

## 소재 운송 시연 — 약 1분

1. 생산 오버뷰에서 정상 생산을 선택하고 Reset합니다. Step0에는 용선 운반차, 용강 운반차, 슬래브를 적재한 HGI 트럭이 각각 운송 중입니다. 상단 운송 3대와 하단 **공정 간 운송** 표를 확인합니다.
2. HGI 트럭 또는 운송 표의 소재 운반 트럭을 선택합니다. 현재 소재 슬래브, 차량 `VEHICLE-HGI-flatbed_truck`, 연주→열연 경로와 26t 화물을 보여줍니다. **도착 공정 · 열연**으로 들어가면 적재 차량을 더 크게 볼 수 있습니다.
3. Play로 차량 이동을 보고 Pause로 정지합니다. Step으로 도착을 확정하면 트럭 적재 상태가 해제되고 열연의 가열로 작업이 시작됩니다. 3D 위치 보간은 표시용이며 실제 공정 시작은 서버가 결정한다고 설명합니다.
4. 정상 Step6에서 GI의 HR 소재가 열연→냉연으로 운송 중이고 산세는 대기임을 보여줍니다. Step7에서 냉연 공정에 도착하고 산세가 시작됩니다. **선택 배치 경로** 탭에서 완료·현재·예정 운송을 비교합니다.
5. **2D 공정**에서도 같은 운송 표와 출발·도착 링크를 사용합니다. 정상/Reset/1×로 종료합니다. 차량 배차·상하차 물리·교통 계산은 예제의 범위 밖입니다.

## 제품 제조 미니어처 시연 — 약 3분

1. [제품 제조공정](http://127.0.0.1:4173/?workspace=journey)을 열고 **열연**, **처음부터**를 선택합니다. 한 소재가 입고 트럭, 가열로, 조압연, 사상압연, 냉각, 권취를 거쳐 제품이 된다고 소개합니다.
2. **재생**을 누릅니다. **소재 따라가기**로 이동을 보고 일시정지합니다. 가열로 또는 압연기를 선택해 설비를 확대하고, **전체 보기**로 돌아갑니다. 설비 선택 자체는 생산 시간을 바꾸지 않습니다.
3. **다음 단계**로 권취 전후를 비교합니다. 소재 계보 ID는 같고 형태와 버전이 변합니다. 최종 출고에서 제품 역할과 20t 질량이 유지되는 것을 확인합니다.
4. **후판**의 냉각대·절단기, **선재**의 블룸→빌렛→선재, **냉연**의 산세·청정·소둔을 선택해 설비와 최종 형태 차이를 보여줍니다.
5. **도금**의 GI·GA·HGI·EG를 바꿔 합금화 유무, HR 투입, 전해조 차이를 확인합니다. **전기강판**의 GO/NGO, **스테인리스**의 세 경로, **티타늄**의 코일/시트/후판도 선택합니다.
6. **2D**에서 공정 선택과 소재 계보가 동일하게 유지됨을 보여줍니다. 열연을 선택하고 초기화한 뒤 **3D / 전체 보기 / 1× / 일시정지**로 종료합니다.

공개 도해를 참고한 자체 미니어처이며 실제 설비 제어나 생산 속도가 아님을 설명합니다. HGI는 독립 원본 모형이 아닌 파생 경로입니다. 이 화면의 단일 소재는 기존 생산 배치·주문·물류와 별도의 합성 시연입니다. [경로·출처·한계](PRODUCT_JOURNEY.md).

제조공정 대체 영상: [열연 실제 재생 MP4](evidence/journey-demo.mp4), [WebM 원본](evidence/journey-demo.webm). 실제 브라우저에서 소재 선택·정지·초기화와 열연 전체 4× 재생을 녹화했습니다. [데스크톱 화면](evidence/journey-desktop-overview.png), [모바일 2D 화면](evidence/journey-mobile-fallback.png).

## 장애 대응

- WebGL 장애: `Open 2D inventory` 또는 `2D inventory` 버튼으로 전환합니다. 코일 선택·연결·시뮬레이션 제어가 유지됩니다.
- 생산 3D 장애: **생산 목록 열기** 또는 **2D 공정**을 선택합니다. 공정 탐색, 소재 계보, 작업 표와 시뮬레이션 제어를 계속 사용할 수 있습니다.
- 제품 제조 미니어처 3D 장애: **2D 공정 보기** 또는 **2D**를 선택합니다. 제품군·경로 선택, 작업 목록, 소재 이력과 재생 제어를 계속 사용할 수 있습니다.
- 백엔드 중단: 화면에 stale snapshot 또는 연결 오류가 표시됩니다. 백엔드를 다시 실행하고 Retry를 누릅니다. 상태가 자동으로 일시정지되어 복원됩니다.
- 인터넷/AI 사용 불가: 설치가 끝난 앱은 로컬에서 동작합니다. 외부 폰트·텍스처·AI 요청을 하지 않습니다.
- 화면/장치 문제: 아래 녹화 영상을 로컬에서 재생합니다. 영상은 실제 합성 시뮬레이션을 조작한 녹화이며 실시간 운영 데이터가 아닙니다.
