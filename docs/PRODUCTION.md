# 같은 주문을 이행하는 생산·물류

생산 화면은 독립 fixture가 아니라 `World.production`의 탐색 투영입니다. 주문 → 작업 지시 → 로트 → 소재 → 버전/계보 → 공정/운송 → 검사/포장 → 출하 명세 → 배송이 같은 실행 ID로 연결됩니다. 현재 운영 화면에는 별도 생산·물류 시계가 없습니다.

서버의 자원 스케줄러는 선행 공정, 투입 소재 형태, 설비 호환성, 용량·예약·점유·장애를 확인합니다. 소재는 공정 중 형상과 버전을 바꾸고, 완료 경계에서 기록을 만듭니다. 공정 사이에는 롤러, 평판 운반차, 용선 운반차, 용강 운반차가 실제 transfer를 처리합니다. 상태는 `WAITING → LOADING → IN_TRANSIT → UNLOADING → ARRIVED`이며 도착 전 다음 공정에 투입하지 않습니다.

## 수량과 검사

초기 추적 질량 408,000 kg + 합성 첨가 1,200 kg = 최종 활성 질량 407,300 kg + 명시적 손실 1,900 kg입니다. ORE는 광석 전체 질량이 아니라 추적하는 합성 금속량입니다. 공정 수율·첨가량·시간은 설명용 fixture이며 실제 제철 수율이나 성능 자료가 아닙니다.

GA 주문 `ORD-ga`는 `LOT-ga-01`의 소재 01/02와 `LOT-ga-02`의 소재 03을 갖습니다. 각 최종 소재는 20,100 kg이며 `SHIP-ga-01` 40,200 kg, `SHIP-ga-02` 20,100 kg가 따로 배송됩니다. 첫 배송 후 `PARTIALLY_DELIVERED`, 배송 잔량 20,100 kg이며 두 번째 배송 후에만 주문이 `DELIVERED`입니다.

후판 `MAT-plate-01`은 자식 `:A`, `:B` 각 9,950 kg로, 티타늄 박판 `MAT-ti-sheet-01`은 자식 둘로 분할됩니다. 부모는 `CONSUMED`/비활성으로 보존하고 최종 검사·재고·출하는 자식의 현재 버전에 연결합니다. 현재 활성 소재와 과거 소재 버전을 함께 질량에 합산하지 않습니다.

생산 완료·최종 검사 통과·포장 완료를 갖춘 소재만 가용 재고가 됩니다. 보류/실패 검사는 가용·출하 실적을 만들지 않습니다. 출하 할당·적재·출발과 배송 완료는 각각 다른 전이입니다. KPIs의 생산/출고/배송 kg는 누적 이행량이며 시간당 생산성이나 실제 SLA가 아닙니다.

## 시나리오

NORMAL은 정상 자원 일정입니다. DELAY는 HSM-A 12 제조분 중단을 실제 스케줄러에 적용합니다. RECOVERY는 장애 1분 후 호환 자원을 검사하고 HSM-B로 우회하며 5분 롤러 이동과 실제 대기·가공 비용을 반영합니다. 이 fixture에서 우회는 배송 개선 이득이 없습니다. 더 늦는 주문과 동일한 주문을 그대로 표시하며 '회복'이라는 이름만으로 개선을 주장하지 않습니다.

ETA는 별도 공식이 아니라 같은 전체 생산·물류 엔진을 복제하여 계산합니다. 시나리오 전환은 기존 실행 도중 일부 상태만 바꾸는 조작이 아니라 동일 초기 계획의 새 실행입니다. 시간 환산, 명령 계약, 기록 보존은 [운영 문서](OPERATIONS.md), 제품 경로는 [제품 제조 경로](PRODUCT_JOURNEY.md)를 참조하십시오.
