# Finishing miniatures

58 individually registered owners, 16 kinds and the sealed 29 source requirements
mapped to 52 host associations. Dimensions and kinetics are synthetic miniature
design assumptions. No external paid or downloaded geometry is used.

`provenance.json` records copied primitive sources by exact hash. This family
never imports hot-rolling or steelmaking authoring code at runtime.

Build only into a new owned evidence root with an independently pinned input
seal. The builder does not install a top-level aggregate manifest or integrate
the factory application. Build completion is not visual or contact approval;
actual GLB, forming, full-cycle and independent evidence are required.
